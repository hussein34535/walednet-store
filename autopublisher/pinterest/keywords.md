## Rules
- Title + description + board + alt text = all must contain the keyword.
- Put the keyword in the first sentence of the description.
- 1 pin links to the landing page (bot link), 2-3 pins per week can link to other
  helpful content (pins are more accepted when the account looks human/generous).
- Post 3-5 pins/day, max 1-2 per board per day.
- Sizes: 1000x1500 (2:3). Text overlay readable at mobile size.
- First 30 days = indexing phase. Do not delete pins; keep posting.
